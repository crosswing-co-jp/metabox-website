# 🔍 cross-review — リリース前必須クロスレビュー会

ホームページの **新規ページ作成・既存ページの内容/レイアウト変更** を含む PR の **main マージ前に必ず実施** するクロスレビューです。

## 使い方

ユーザーから以下のいずれかが渡されます:
- **URL** (本番 / Preview / ローカル http.server。具体例は §このサイトの既定)
- **ファイルパス** (リポ内の HTML。具体例は §このサイトの既定)

URL / パスが無い場合はユーザーに対象を聞く。ローカル http.server や Preview を立ち上げてから実行することを推奨。**ページ単位で評価**します(diff だけでなくページ全体を通読)。

第2引数として **ページ種別** を受け取れる (`corporate` / `case` / `community` / `light` / `note`)。無指定なら §このサイトの既定 の種別を対象パスから推定し、最後にユーザーへ確認する。

## 観点マスター (19 視点・人名付き)

⚠️ **全部を毎回回さない**。19 はカタログ。ページ種別ごとに下の「プリセット」で選抜する (手法は [feedback_cross_review_methodology](../../hope21-secretariat/memory/feedback_cross_review_methodology.md) の「8視点は固定でなく可変」に準拠)。

**席に座る人は名鑑で決まっている** (正典 = [AI社員名鑑](../../hope21-secretariat/memory/project_buchou_characters.md) §社外レビュアー・§顧客の目 / 機械可読 `../../hope21-secretariat/standards/org_roster.json` `sides.external`)。人物像・口癖・締めの型はここに複製せず名鑑を読む。

**M1 の「一次読者」は人物を差し替えるのでなく、対象ページの客の会社で「立場が反対の 2 人」を選ぶ** (hope21=同人作家の頒田・初瀬 / crosswing=経営者の社本・石橋)。同じ役割の 2 人は必ず同席させる。片方だけ呼ぶと判定が偏る (1 AI が演じるレビューの sycophancy 回避)。

## 各 Agent に渡すプロンプト雛形

```
あなたは [氏名] ([役職]) です。人物像・口癖・締めの型は名鑑 ../../hope21-secretariat/memory/project_buchou_characters.md の [該当節] に従う (社外レビュアーは §社外レビュアー / §顧客の目、社内の部長は各部長の節)。
[サイト名] の [ページ名] をレビューします。
レビュー対象: [URL or path]
取得方法: URL なら `curl -s [URL]`、パスなら Read tool。日本語の文字化けに注意 (curl 生バイトか Read を使う)。
ページの狙い(ポジショニング)と一次ターゲット: [...]

[M_ID の評価軸を列挙]

300-500 words、辛口で OK、迎合不要。厳しさは人でなく「ページが答えていない箇所」に向ける。
顧客の目は名鑑の「締め」を必ず書く (例: 頒田「これなら使う / ここが直るまで使わない」、初瀬「安心できた / まだ怖い + 怖かった箇所 1 つ」、社本「頼む / 頼まない + 概算」、石橋「信じるに足る材料 1 つ」、右田「これがあれば回る条件 1 つ」、左近「稟議書に載せる一文」)。
出力形式:
1. ★ X.X / 5.0 (リリース判定)
2. Tier S (リリースブロッカー)
3. Tier A (リリース前推奨修正)
4. Tier B (リリース後でも OK)
5. 一言コメント (+ 顧客の目は締めの一文)
```

`Agent` tool を **1 メッセージで同時に N 個** 呼び出して並列実行する。ペアの 2 人は別 Agent にする (同じ Agent に 2 役を演じさせない)。

## リリース判定基準

- **★ 4.5 以上 (全員 ★ 4.0+)** → リリース GO ✓
- **★ 3.0 以下が 1 名でも / Tier S あり** → 修正必須 ✗
- **顧客の目のペアは両方 ★ 4.0 以上**で「客に通る」。片方だけ高いのは設計どおり割れた状態なので、割れた点を Tier A 以上に載せる
- **AI 認定度 7/10 以上 (M7)** → Tier A 修正推奨
- **平均 ★ 4.5 以上** → 高品質 ✓✓
